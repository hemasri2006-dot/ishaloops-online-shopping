# IshaLoops Online Shopping

A full-stack e-commerce web application built using Flask, MySQL, HTML5, CSS3, and Jinja2. The application provides a complete online shopping experience with user authentication, product browsing, shopping cart, checkout, order management, and admin product management.

## 🚀 Features

- User Registration and Login
- User Logout and Session Management
- Product Catalog
- Product Details
- Shopping Cart
- Cart Quantity Management
- Checkout and Order Placement
- My Orders
- Admin Dashboard
- Add Products
- Edit Products
- Delete Products
- Admin Order Management
- MySQL Database Integration
- Responsive Web Design
- Form Validation and Error Handling

## 🛠️ Technologies Used

- Python
- Flask
- MySQL
- HTML5
- CSS3
- Jinja2
- MySQL Connector/Python
- Visual Studio Code
